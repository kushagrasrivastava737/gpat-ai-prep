# 🎓 GPAT AI Prep

### AI-Powered GPAT Preparation & Performance Analysis Platform

GPAT AI Prep is a smart learning platform designed to help pharmacy students prepare for the Graduate Pharmacy Aptitude Test (GPAT) using **AI-assisted learning, adaptive practice, performance analytics and personalized study recommendations**.

## 🚀 Core Features

* 📚 Subject-wise GPAT Question Bank
* 🧠 AI-assisted Question Explanations
* 📝 Mock Tests
* 📊 Performance Analytics
* 🎯 Weak Topic Detection
* 🤖 Personalized Study Recommendations
* ⏱️ Timed Practice
* 📈 Progress Tracking

## 🧠 AI Logic

The platform analyzes a student's:

* Accuracy
* Attempt history
* Response time
* Subject performance
* Topic-wise mistakes
* Repeated incorrect answers

to identify weak areas and generate personalized study recommendations.
